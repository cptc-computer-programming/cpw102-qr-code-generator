# GitHub Setup and Submission

1. On the assignment repository, choose **Use this template** and **Create a new repository**.
2. Under your own account, create a private repository named `lastname-cpw102-qr-code-generator`.
3. Under **Settings → Collaborators**, invite `rachelkingCPTC` so your instructor can review your work.
4. Choose **Code → Open with GitHub Desktop** and clone your repository.
5. Before editing, use **Current branch → New branch** to create `development`. Publish the branch.
6. Choose **Repository → Open in Visual Studio Code**. Follow the [assignment instructions](README.md).
7. Commit your changes to `development` and push them to GitHub.
8. Open a pull request with `main` as the base and `development` as the compare branch. Review the changes and merge.
9. Submit your GitHub repository URL in Canvas.
